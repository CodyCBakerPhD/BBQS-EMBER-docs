# EMBER-DANDI: Account Setup
EMBER-DANDI is the subsystem of the EMBER archive designed to store **de-identified, non-PHI/PII** data, which can include both animal and human data. It is suitable for human neural and behavioral experiments with **non-sensitive** data. EMBER-DANDI data is intended to eventually be open to the public, but does support embargoed datasets which would remain private for a set period of time (i.e., after results have been published).

--- 

# GitHub Account Setup

1. Create a GitHub Account
    - If not already a GitHub user, sign up [here](https://github.com/).
2. Register on EMBER
    - Navigate to the EMBER-DANDI [portal](https://dandi.emberarchive.org/) and click the Login button in the top right corner.
3. Account Review and Approval
    - After registering, you will receive an email confirming that your account is under review.
    - While we try to review and approve accounts as soon as possible, this is a manual process and some reviews may take an extended time, especially for new GitHub accounts or non .edu email addresses.
4. Access EMBER
    - Upon approval, you will be able to access EMBER by logging in through the Login button in the top right corner.
